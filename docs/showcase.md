# Nova 能力展示

以下是一些 Nova 能帮你完成的真实场景。全部用自然语言描述即可，不需要记指令。

> **提示**：直接说你想做什么，Nova 会自动选择合适的工具来完成。

---

## 日常办公

### 撰写和修改文档

```
帮我写一封邮件给客户，确认下周二的会议时间，语气要礼貌专业。
```

Nova 直接生成邮件草稿。不满意可以接着说：

```
改成更轻松的语气，加上产品演示的日程链接。
```

### 信息整理

```
把这个网页里的表格提取出来：
https://tradingeconomics.com/china/gdp
```

Nova 打开网页，定位到表格区域，提取内容，整理成结构化格式给你。

### 网页搜索与总结

```
帮我查一下今年最新的 iPhone 发布了哪些型号，有什么区别。
```

Nova 搜索多个来源，汇总关键信息，给你一份简洁的对比总结。

### 跨语言翻译

```
把这份 Readme 文件翻译成中文，保留 Markdown 格式。
```

Nova 读取文件，逐段翻译，输出完整的翻译版本。

### 优化简历

```
帮我看看这份简历，给出修改建议让它更有竞争力：
~/Documents/我的简历.docx
```

Nova 读取简历内容，从措辞、结构、量化成果等角度给出具体修改建议。你也可以让它直接改写：

```
帮我把这份简历的工作经历改写得更有冲击力，用 STAR 法则重新组织。
```

### 下载页面里的资源

```
这个电台页面里正在放一首歌，帮我下载到本地：
https://www.fangpi.net/music/11831013
```

Nova 打开电台页面，定位到音频播放器，提取歌曲文件地址并保存到本地：

```
已下载到 ~/Downloads/当前播放歌曲.mp3
```

也可以提取页面里的所有可下载资源：

```
打开这个页面，帮我找出里面所有图片和视频的下载链接。
```

Nova 扫描页面中的 `<img>`、`<video>`、`<audio>` 标签，列出所有媒体文件的地址。

## 创意设计

### 写广告文案

```
帮我想几句这款智能手表的海报 slogan，卖点是续航 30 天和全天健康监测。
```

Nova 根据产品卖点，生成多个文案方向供你挑选。不满意可以直接说：

```
太长了，帮我缩到 8 个字以内，要更有冲击力。
```

### 提取参考网站的配色和字体

```
打开这个页面，帮我把它的配色方案和字体提取出来：
https://www.apple.com/
```

Nova 打开页面，分析 CSS 和页面元素，提取主色、辅色和字体信息。

### 批量导出素材

```
把设计稿文件夹里所有 .svg 统一导出为 .png，尺寸设成 2x。
```

Nova 调用本地工具批量转换，所有文件都在你电脑上处理。

### 搜索设计灵感

```
帮我看一下今年平面设计有哪些流行趋势，总结几个关键词和方向。
```

Nova 搜索多个设计社区和趋势报告，汇总关键信息给你。

### 方案对比

```
帮我对这两版海报设计方案做个对比分析，从视觉冲击力、信息层级、适用场景几个角度。
```

Nova 读取你的方案说明或参考文件，给出客观对比和建议。

### 写设计说明

```
帮我把这张海报的设计理念写一段介绍文字，用于作品集，风格要专业但不生硬。
```

Nova 根据你提供的设计思路或关键词，生成完整的设计说明。

### 找免费商用资源

```
帮我找几个免费可商用的中文字体，适合用在美妆品牌 VI 里。
```

Nova 搜索字体网站，筛选出符合条件的字体，附上下载地址和授权说明。

## 内容创作

### 写公众号文章

```
帮我写一篇介绍如何用 AI 提高工作效率的文章，面向普通上班族，
语言要通俗易懂，2000 字左右。
```

Nova 生成完整文章。不满意可以接着改：

```
太正式了，改成更轻松的口吻，多举一些具体例子。
```

### 写小红书笔记

```
帮我把这款无线耳机写一篇小红书种草笔记，突出音质好和佩戴舒适。
```

Nova 按小红书风格生成图文文案和标签。

### 写产品文案

```
帮我写一段智能水杯的产品介绍，用于官网首页，50 字以内。
```

Nova 产出多个版本供你挑选。

### 起标题 / 写摘要

```
帮我把这篇文章缩写成 3 句话摘要，再想 5 个吸引人的标题。
```

Nova 阅读文章内容，提取要点，生成标题候选。

### 润色 / 改写

```
帮我把这段产品描述改得更专业，不要改变原意。
```

Nova 优化措辞和表达，保持信息准确。

## 文件与数据处理（本地完成，不传云端）

### 分析本地 CSV

```
帮我分析桌面上的 6 月支出.csv，看看这个月钱主要花在哪几类了。
```

Nova 读取你的本地 CSV 文件，分类统计，给出占比和排名——数据不需要上传到任何云端。

### 合并文本文件

```
把 downloads 文件夹里所有 .txt 文件合并成一个文件。
```

Nova 用一条命令完成合并。

### 压缩图片

```
把这个文件夹里的 .png 图片压缩一下，减小文件体积。
```

Nova 用本地工具批量压缩，不会把你的图片传到任何服务器。

### 实时信息查询

```
今天北京天气怎么样？需要带伞吗？
```

Nova 查询天气网站，告诉你温度、降水概率和穿衣建议。

这篇论文太长了，帮我总结一下核心观点和结论。

## 记忆功能

跨会话记忆让 Nova 能记住你的偏好和信息，不需要每次重复。

### 记住个人信息

```
记住我的邮箱是 andy@example.com。
```

下次你只需要说：

```
我的邮箱是什么？
```

Nova 会从记忆中调出来。

### 记录重要信息

```
记一下：我家 WiFi 密码是 NovaIsGreat2024。
```

以后：

```
我家的 WiFi 密码是多少？
```

Nova 会从记忆中调出来。
