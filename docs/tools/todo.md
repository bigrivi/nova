# Task Management

## `todo_write`

The `todo_write` tool manages a task list during your session. The agent can
create, update, and track progress on tasks.

```text
Plan out the steps needed to implement a login system
```

### Task States

- `pending` -- not started
- `in_progress` -- actively being worked on
- `completed` -- finished
- `cancelled` -- no longer needed

### Priorities

- `high`
- `medium`
- `low`

The task list is displayed in the conversation so you can track progress at a
glance.
