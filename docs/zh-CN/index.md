# Nova

[English](../index.md) · 中文

Nova 是一个跑在本地的个人 AI Agent。它运行在你的机器上，用你选的模型（本地或云端），
跨会话记住上下文，还能执行代码、浏览网页、搜索文件、执行 shell 命令，等等。
